## 下单前必须问清的 6 件事

这 6 条不分商家，在哪买都适用。答不上来的，先放一放。

1. **开在谁的账号上？** 只认开到自己账号里的。塞给你一个现成账号、或者让你用他网站账号登录的，都不是代充，是租号。
2. **要你交出什么？** 一串能定位账号的编号就够了。张口要密码、要邮箱或手机验证码、要浏览器 Cookie、要证件照的，换一家。
3. **价格说不说得通？** 拿官方折算价当基准量一遍，差额能不能用渠道和售后解释清楚。
4. **到账时间和失败处理，页面上写没写？** 只回一句「有事找客服」的不算写清楚。
5. **会员半路没了补不补？** 补多久、补到哪个账号，要有文字，不能只是口头承诺。
6. **出了事找得到人吗？** 联系方式要固定、可核实。陌生人主动加你好友、自称客服或助理的，多留个心眼。

## 组织 ID 在哪找，为什么只给这一样

Claude 的会员认的是账号背后的「组织」，不是登录邮箱。卖家要 Organization ID，就是为了确认会员该落到哪个账号、开哪一档。

位置：先登录你日常在用的那个 Claude 账号，左下角头像 → 设置（Settings）→ 账号（Account），页面里有一行 Organization ID，是一串带横线的字母数字（UUID 格式），复制下来。

这串编号登录不了你的账号，也看不到你的对话。真正要守住的是四样东西：**账号密码、邮箱或手机验证码、浏览器登录 Cookie、证件照片**。哪家开 Claude 问你要其中任何一样，直接换。

有两个容易复制错的场景：手上有好几个邮箱的，Google 登录和邮箱直接登录可能是两个不同的号；进过团队空间的，别把团队的组织 ID 交上去。

## 付完钱之后：四处验收，五种排查

到账后先登出再登入，网页端和 App 各登一次，然后看四个地方：

- **设置 → 账单（Billing）**：套餐一栏写的是 Pro plan、Max plan 还是 Ultra plan。
- **设置 → 用量（Usage）**：付费套餐这里会出现进度条，一条 5 小时会话、一条每周上限，旁边标着重置时间。买的是已认证的 Ultra，只看到每周那一条是正常的。
- **模型下拉**：能选 Opus 了。免费版用不了 Opus，这是官方定价页写明的。
- **Claude Code**：终端里输入 `/status`，确认登录的是你自己的 Claude 账号；不是就 `/login` 换过来。系统环境变量里设了 `ANTHROPIC_API_KEY` 的，Claude Code 会优先用这个 Key 按 API 计费，用不上就删掉再重开终端。

还是显示 Free plan，按这个顺序查：

1. 页面或 App 停在旧状态。登出重登，App 顺手升个级。
2. 当前登录的邮箱不是开会员那个。设置里对一下邮箱。
3. 用 Apple 登录时选了隐藏邮箱。账号邮箱是 `privaterelay.appleid.com` 结尾的转发地址，换设备登录也得走 Apple 登录。
4. 当前停在团队（Team）空间。从账户菜单切回个人账户。
5. 钱交到了 platform.claude.com（原 console.anthropic.com）。那是开发者平台的 API 余额，按用量扣费，跟会员不是一本账，也不能互转。

用起来之后还会碰到三条英文提示，它们讲的是额度和服务器，跟会员开没开成无关：

| 提示 | 含义 | 怎么办 |

| `5-hour limit reached - resets [时间]` | 5 小时额度用完（已认证的 Ultra 不出这条） | 等到提示里的时间 |

## 这几种情况，别买代充

- **账号已经是 Pro、Max 或 Ultra 的**：代充方没法在已有订阅上叠加或覆盖，得换一个当前是免费版的账号。想升级档位也一样。
- **有能付外币的卡，或有外区 Apple ID / Google Play 账号的**：自己开更省事，官方网页收信用卡和借记卡，App 内购走应用商店，出问题直接找官方。
- **想充 API 余额的**：那是 platform.claude.com 上的另一套账，跟会员订阅不能互转。
- **指望封号包赔的**：没有一家保这个。现在这个风控强度下，环境不干净的新号开上去，掉得比用得还快。

另外两类东西经常被当成代充卖，其实不是：成品号、共享号、拼车 Max，邮箱和找回权在别人手里，几个人异地登录容易被停用；镜像站、套壳网站，进不了 claude.ai 和 Claude Code，对话还存在别人的服务器上。
